# Relatório (formato SBC)

O relatório **deve** usar o template SBC enviado junto com a especificação do projeto, sem alterar margens, fontes, espaçamento ou colunas. Fora desse formato, a nota de Comunicação é 0.

1. Copie para esta pasta os arquivos do template SBC fornecidos pelo professor.
2. Escreva o relatório neles (use a skill `relatorio-sbc` no Claude Code).
3. Gere o PDF final e salve aqui (`reports/fraudazero.pdf`).
